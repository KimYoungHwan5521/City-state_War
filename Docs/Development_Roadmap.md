# Little Civilization 개발 일정표

최종 갱신: 2026-09-02
규칙 기준서: [Prototype_Rules_Master.md](./Prototype_Rules_Master.md)

## 진행 원칙

- 단계는 아래 순서대로 진행하되, 다음 단계에 필요한 안전한 기반 작업은 먼저 할 수 있다.
- 각 단계의 `완료 조건`을 실제 빌드와 테스트로 검증한 뒤에만 단계 제목을 완료 처리한다.
- 일부 코드만 작성된 상태는 완료가 아니다.
- 규칙 변경은 먼저 규칙 기준서에 반영하고 구현 및 테스트를 갱신한다.
- 게임 규칙은 가능한 한 Unity 화면 코드와 분리된 순수 C# 시뮬레이션으로 작성한다.
- 모든 플레이 행동은 명령으로, 처리 결과는 이벤트로 기록한다.
- 같은 초기 상태, 난수 시드, 명령 목록은 항상 같은 결과를 만들어야 한다.
- 밸런스 수치는 코드에 직접 고정하지 않고 데이터로 관리한다.
- 새로운 단계에 착수할 때는 구현 전에 해당 단계의 세부 작업·검증 체크리스트와 현재 진행 위치를 먼저 추가한다.

## 첫 테스트 플레이 — 5단계 통합 검증

목적: 6단계의 병종·방어시설을 추가하기 전에, 현재까지 만든 도시 운영·동시 턴·전투·보급의 핵심 흐름을 실제 조작으로 검증한다. 이 테스트에서는 밸런스 확정보다 **조작 가능 여부, 규칙 전달, 진행 불능 버그 발견**을 우선한다.

테스트 환경:

- [x] Unity 에디터 Play Mode에서 로컬 핫시트 1대1로 진행한다.
- [x] 새 게임을 최소 2회 시작하고, 한 게임은 정부청사 함락 또는 명백한 진행 불능 상태까지 진행한다.
- [x] 발견한 문제를 `진행 불가`, `규칙 오작동`, `UI·설명 부족`, `밸런스 의견`으로 구분해 기록한다.

확인 범위:

- [x] 게임 시작 시 양 도시의 정부청사·인구 4·시작 금 10·민병대 1명이 올바르게 생성된다.
- [x] 타일, 정부청사, 특수지구와 타일 위 병력을 마우스로 선택할 수 있고 선택 정보가 올바르게 표시된다.
- [x] 미배정 시민으로 서로 다른 빈 타일에 복수 지구를 예약하고, 예약 취소·건설 진행·완공 후 자동 시민 배치를 확인한다.
- [x] 정부청사와 완공 지구의 식량·금·과학·문화 기본 산출, 시민 소비와 성장 진행이 UI 계산 내역과 일치한다.
- [x] 각 도시에 식량 자원 3개와 상업·과학·문화 자원 각 1개가 정해진 거리 안에 산개한다.
- [x] 자원 타일이 대응 특수지구 색상의 작은 네모로 표시되고 타일 선택 정보에도 자원 종류가 표시된다.
- [x] 대응 자원 위에 농업·상업·과학·문화지구를 완공하면 종류별 자원 보너스가 실제 산출에 적용된다.
- [x] 서로 인접한 같은 종류의 상업·과학·문화지구가 지구당 +1, 최대 +2의 인접 보너스를 받고 지구 정보와 도시 산출에 표시된다.
- [x] 군사지구에서 민병대와 보급병을 훈련하고, 비용 지불·고정 훈련 턴·완성 턴 행동 금지·유지비 지불을 확인한다.
- [x] 양 플레이어가 상대에게 명령을 노출하지 않고 이동을 예약·수정·취소·확정할 수 있다.
- [x] 양측 확정 후 이동 우선권, 경로 차단, 자동수비, 공격 대 공격, 전투·우회·대기 재명령이 예상대로 처리된다.
- [x] 병력의 이동력과 타일당 전투부대 3개·보급부대 별도 1개 제한이 지켜진다.
- [x] 도시 식량을 병력에 적재하고 같은 타일의 아군 병력끼리 식량을 전달할 수 있다.
- [x] 원정군의 식량 소비, 보급 시 비례 회복, 첫 보급 실패의 굶주림, 다음 연속 실패의 전멸을 확인한다.
- [x] 전투 사망 시 현장 식량 생성, 점유군 획득, 빈 자국 타일 한 턴 유예 후 본국 귀속을 각각 확인한다.
- [x] 빈 특수지구 점령과 점령 중 생산 정지, 빈 정부청사 함락에 의한 정복승리를 확인한다.
- [x] 금 부족 시 병력 강제 해체와 적재 식량 본국 반환이 우선순위대로 처리된다.
- [x] 최소 20턴 동안 예외, 입력 먹통, 턴 정지, 상태 불일치 없이 플레이할 수 있다.

이번 테스트에서 제외:

통과 기준:

- [x] 징병 병력이 최대 군량으로 등장하고 30턴 동안 원 소속 도시의 수비군 공격·지구 점령·약탈 명령이 모두 차단된다.
- [x] 군사도시는 징병 후에도 정부청사에 최소 수비병 1명을 남긴다.
- [x] 징병 병력이 사망하면 반환 명단에서 즉시 제거되고 생존자가 없으면 징병 상태가 종료된다.
- [x] 두 플레이어의 동시 징병 요청이 비공개 경매 규칙대로 처리된다.
- [x] 같은 군사도시 동시 징병에서는 할인 전후 기본가격이 아니라 추가 제시금만 비교하며, 추가금 동률이면 양쪽 모두 실패한다.
- [x] 중립도시 AI는 점령에서 벗어난 약탈 지구의 수리를 자동으로 시작한다.
- [x] 중립도시 AI는 상업·과학·문화지구를 추가 건설할 때 가능한 타일 중 동종 지구 인접 보너스를 우선한다.
- [x] 징병 입찰은 경쟁 여부와 관계없이 성공·패배·동률 결과를 턴 전투 로그에 표시한다.
- [x] 굶주림 진입과 군량 부족 전멸이 턴 로그에 병력 ID와 함께 표시된다.
- [x] 중립도시 특수지구 타일을 선택하면 건설 중·점령·약탈·수리·유지비 정지·가동 상태가 표시된다.
- [x] 징병 종료·조기 해산 시 생존 병력과 군량이 원 도시로 정상 반환된다.

명령·전투·시설 추가 회귀:

- [x] 도시 정보 패널에 정부청사·지구 종류별 배치 시민과 미배정 시민 수가 표시된다.
- [x] 다른 플레이어가 예약한 지구 건설은 취소 버튼이 노출되지 않고 취소할 수도 없다.
- [x] 염지·통조림 연구 완료 및 징병 만료가 아닌 상황에서 병력이 정부청사로 순간이동하지 않는다.
- [x] 징병 만료 병력은 원 도시로 순간이동하지 않고 통제권 반환 후 지도에서 직접 귀환한다.
- [x] 핵시설은 일반 빈 타일과 명확히 다른 색으로 표시되고 도시당 하나만 건설할 수 있다.
- [x] 건설 중인 특수지구는 점령될 수 있어도 약탈 상태·약탈 보상이 발생하지 않는다.
- [x] 약탈은 점령 병력에게 이동력이 남아 있을 때만 발생하며, 다음 일반 턴 이동력 회복 시 미약탈 점령지를 약탈한다.
- [x] 핵시설 최초 약탈 보상은 금 10으로 로그와 실제 보유 금에 명확히 표시된다.
- [x] 성벽·해자·현대방어체계는 정부청사에서만 건설할 수 있다.
- [x] 병력 생산은 예약 단계와 실제 진행 단계 모두 취소할 수 있고, 진행 중 취소 시 생산비 전액을 돌려받는다.
- [x] 지구 건설은 예약 단계와 실제 진행 단계 모두 취소할 수 있고, 배치된 시민과 지불한 건설비를 돌려받는다.
- [x] 적 병력 타일 우클릭 시 교전 예상 결과가 표시된다.
- [x] 명령 시점부터 예상된 적과의 교전은 기동 재명령을 만들지 않고, 동시턴 처리로 새로 생긴 길막힘만 기동 재명령을 만든다.
- [x] 이동 우선권 상실 또는 타일 병력 한도 초과로 장거리 이동이 중단되면 기존 경로를 취소하고, 이동력이 남은 병력을 자동 선택해 기동 재명령 단계를 연다.
- [x] 플레이어가 자기 병력을 해체하면 유지비 대상에서 제거되고 적재 군량은 출신 도시로 반환된다.
- [x] 병력 정보의 체력을 `현재 HP/최대 HP` 형식으로 표시한다.
- [x] 게임 종료 화면과 치트 패널에서 첫 턴부터 경기를 다시 시작할 수 있다.
- [x] 모든 패널과 버튼의 사용자 노출 용어를 한국어로 통일한다.
- [x] 같은 타일의 복수 병력을 선택해 한 번에 같은 경로로 이동 예약할 수 있다.
- [x] 적 영토의 현장 군량을 버튼으로 습득할 수 있고, 그 타일에서 이동할 때 빈 적재량만큼 자동 습득한다.
- [x] 양 플레이어가 같은 턴에 서로의 정부청사를 점령하면 정복승리를 판정하지 않고 인구·금·식량·산출·지구·타일·생산 대기열을 포함한 도시 기지 전체 소유권을 교환한 채 경기를 계속한다.
- [x] 동시 교차 점령 후에도 양측 기존 병력의 소유권·제어권은 바뀌지 않는다.
- [x] 기지 교환 후 기존 병력의 출신·보급 도시와 훈련·핵 프로젝트 소유자를 새 기지에 맞게 변경하고, 새 도시 소유권 기준으로 지구 점령·약탈을 다시 판정한다.
- [x] 동시 정복 기지 교환을 두 도시 이름과 함께 로그에 표시하고, 전투·이동 로그의 지난 기록을 스크롤해서 확인할 수 있다.
- [x] 이미 정부청사가 점령된 중립도시에서는 다른 특수지구에 신규 약탈이 발생하지 않는다.
- [x] 중립도시가 정부청사를 탈환하거나 독립하면 실제 약탈되지 않은 완공 지구가 원소유자 지배와 가동 상태를 회복한다.
