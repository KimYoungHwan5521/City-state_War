# Little Civilization 개발 일정표

최종 갱신: 2026-09-01
규칙 기준서: [Prototype_Rules_Master.md](./Prototype_Rules_Master.md)

## 진행 원칙

- 단계는 아래 순서대로 진행하되, 다음 단계에 필요한 안전한 기반 작업은 먼저 할 수 있다.
- 각 단계의 `완료 조건`을 실제 빌드와 테스트로 검증한 뒤에만 단계 제목을 완료 처리한다.
- 일부 코드만 작성된 상태는 완료가 아니다.
- 규칙 변경은 먼저 규칙 기준서에 반영하고 구현 및 테스트를 갱신한다.
- 게임 규칙은 가능한 한 Unity 화면 코드와 분리된 순수 C# 시뮬레이션으로 작성한다.
- 모든 플레이 행동은 명령으로, 처리 결과는 이벤트로 기록한다.
- 같은 초기 상태, 난수 시드, 명령 목록은 항상 같은 결과를 만들어야 한다.
- 밸런스 수치는 코드에 직접 고정하지 않고 데이터로 관리한다.
- 단계가 완료될 때마다 이 문서의 체크박스, 현재 단계, 변경 기록을 갱신한다.
