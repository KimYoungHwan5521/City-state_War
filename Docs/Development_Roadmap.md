# Little Civilization 개발 일정표

최종 갱신: 2026-09-01
규칙 기준서: [Prototype_Rules_Master.md](./Prototype_Rules_Master.md)

## 진행 원칙

- 단계는 아래 순서대로 진행하되, 다음 단계에 필요한 안전한 기반 작업은 먼저 할 수 있다.
- 각 단계의 `완료 조건`을 실제 빌드와 테스트로 검증한 뒤에만 단계 제목을 완료 처리한다.
- 일부 코드만 작성된 상태는 완료가 아니다.
- 규칙 변경은 먼저 규칙 기준서에 반영하고 구현 및 테스트를 갱신한다.
- 게임 규칙은 가능한 한 Unity 화면 코드와 분리된 순수 C# 시뮬레이션으로 작성한다.
- 모든 플레이 행동은 명령으로, 처리 결과는 이벤트로 기록한다.
- 같은 초기 상태, 난수 시드, 명령 목록은 항상 같은 결과를 만들어야 한다.
- 밸런스 수치는 코드에 직접 고정하지 않고 데이터로 관리한다.
- 단계가 완료될 때마다 이 문서의 체크박스, 현재 단계, 변경 기록을 갱신한다.

## 현재 상태

- 현재 목표: 로컬 핫시트 조작과 기존 코어 규칙을 실제 플레이 화면에서 검증

## 첫 테스트 플레이 — 5단계 통합 검증

목적: 6단계의 병종·방어시설을 추가하기 전에, 현재까지 만든 도시 운영·동시 턴·전투·보급의 핵심 흐름을 실제 조작으로 검증한다. 이 테스트에서는 밸런스 확정보다 **조작 가능 여부, 규칙 전달, 진행 불능 버그 발견**을 우선한다.

테스트 환경:

- [x] Unity 에디터 Play Mode에서 로컬 핫시트 1대1로 진행한다.
- [x] 새 게임을 최소 2회 시작하고, 한 게임은 정부청사 함락 또는 명백한 진행 불능 상태까지 진행한다.
- [x] 발견한 문제를 `진행 불가`, `규칙 오작동`, `UI·설명 부족`, `밸런스 의견`으로 구분해 기록한다.

확인 범위:

- [x] 게임 시작 시 양 도시의 정부청사·인구 4·시작 금 10·민병대 1명이 올바르게 생성된다.
- [x] 타일, 정부청사, 특수지구와 타일 위 병력을 마우스로 선택할 수 있고 선택 정보가 올바르게 표시된다.
- [x] 미배정 시민으로 서로 다른 빈 타일에 복수 지구를 예약하고, 예약 취소·건설 진행·완공 후 자동 시민 배치를 확인한다.
- [x] 정부청사와 완공 지구의 식량·금·과학·문화 기본 산출, 시민 소비와 성장 진행이 UI 계산 내역과 일치한다.
- [x] 각 도시에 식량 자원 3개와 상업·과학·문화 자원 각 1개가 정해진 거리 안에 산개한다.
- [x] 자원 타일이 대응 특수지구 색상의 작은 네모로 표시되고 타일 선택 정보에도 자원 종류가 표시된다.
- [x] 대응 자원 위에 농업·상업·과학·문화지구를 완공하면 종류별 자원 보너스가 실제 산출에 적용된다.
- [x] 서로 인접한 같은 종류의 상업·과학·문화지구가 지구당 +1, 최대 +2의 인접 보너스를 받고 지구 정보와 도시 산출에 표시된다.
- [x] 군사지구에서 민병대와 보급병을 훈련하고, 비용 지불·고정 훈련 턴·완성 턴 행동 금지·유지비 지불을 확인한다.
- [x] 양 플레이어가 상대에게 명령을 노출하지 않고 이동을 예약·수정·취소·확정할 수 있다.
- [x] 양측 확정 후 이동 우선권, 경로 차단, 자동수비, 공격 대 공격, 전투·우회·대기 재명령이 예상대로 처리된다.
- [x] 병력의 이동력과 타일당 전투부대 3개·보급부대 별도 1개 제한이 지켜진다.
- [x] 도시 식량을 병력에 적재하고 같은 타일의 아군 병력끼리 식량을 전달할 수 있다.
- [x] 원정군의 식량 소비, 보급 시 비례 회복, 첫 보급 실패의 굶주림, 다음 연속 실패의 전멸을 확인한다.
- [x] 전투 사망 시 현장 식량 생성, 점유군 획득, 빈 자국 타일 한 턴 유예 후 본국 귀속을 각각 확인한다.
- [x] 빈 특수지구 점령과 점령 중 생산 정지, 빈 정부청사 함락에 의한 정복승리를 확인한다.
- [x] 금 부족 시 병력 강제 해체와 적재 식량 본국 반환이 우선순위대로 처리된다.
- [x] 최소 20턴 동안 예외, 입력 먹통, 턴 정지, 상태 불일치 없이 플레이할 수 있다.

이번 테스트에서 제외:

- 연구·과학승리·문화승리
- 중립도시·교역·징병·AI
- Photon Fusion 2 온라인 멀티플레이
- 최종 그래픽·연출·사운드·튜토리얼

통과 기준:

- [x] `진행 불가` 문제가 0건이다.
